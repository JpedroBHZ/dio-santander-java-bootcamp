## 📝 Sobre o Bootcamp
O **Bootcamp Santander 2026 - AI Java Back-end** é um programa intensivo focado na formação de desenvolvedores de software altamente capacitados na stack Java Back-end, com uma forte imersão em soluções integradas com Inteligência Artificial moderna.

Este repositório foi estruturado de forma cirúrgica para servir como o **Hub Central de Estudos**, onde cada curso, mentoria, desafio de código e de projeto possui sua pasta dedicada contendo anotações de alto valor técnico e a implementação prática dos códigos.

---

## 🛡️ Stack Tecnológica & Aprendizados Principais
*   **Linguagem & Paradigmas:** Java 17/21, Sintaxe, Controle de Fluxo, Orientação a Objetos (OO), Interfaces, Lambdas, Streams API, Java Collections.
*   **Boas Práticas & Arquitetura:** SOLID, Clean Code, Design Patterns Clássicos (GoF), Injeção de Dependências com Spring Framework.
*   **Persistência de Dados:** JDBC nativo, JPA, Hibernate, Spring Data JPA, Bancos de Dados (H2, MySQL, PostgreSQL).
*   **Ecossistema Spring:** Spring Boot 3.x, Spring Web (REST APIs), Spring Security (Autenticação/Autorização JWT), Spring Cloud (OpenFeign para consumo de APIs externas).
*   **Inteligência Artificial & Produtividade:** Engenharia de Prompts, Machine Learning, LLMs, Chatbots Inteligentes, Agentes Autônomos, Integração de APIs de Reconhecimento de Fala com Spring Boot.

## 💻 Instruções de Desenvolvimento Local

Para rodar os projetos desenvolvidos ao longo do bootcamp localmente, siga os pré-requisitos gerais:

### Pré-requisitos
*   **Java JDK**: Versão 21 ou superior.
*   **IDE**: IntelliJ IDEA Community/Ultimate, Eclipse ou VS Code.
*   **Gerenciador de Dependências**: Apache Maven ou Gradle.
*   **Banco de Dados**: H2 Database (em memória para testes rápidos), MySQL ou PostgreSQL.

### Como Executar qualquer Projeto Spring Boot
1.  Navegue até a pasta correspondente ao Desafio de Projeto.
2.  Importe a pasta como um projeto Maven na sua IDE.
3.  Configure as propriedades de banco de dados e IA no arquivo `src/main/resources/application.properties` ou `application.yml` (se aplicável).
4.  Execute a classe principal da aplicação ou utilize o Maven CLI:
    ```bash
    ./mvnw spring-boot:run
    ```
