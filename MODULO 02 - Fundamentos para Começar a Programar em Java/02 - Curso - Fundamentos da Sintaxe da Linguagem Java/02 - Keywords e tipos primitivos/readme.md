Tipos primitivos são os tipos de dados mais básicos e simples do Java. Eles servem para guardar valores numéricos, letras ou estados de verdadeiro/falso diretamente na memória do computador.

Resumo Direto

O que fazem: Guardam a informação direto na memória, sem complicação.

O que não são: Não são objetos (por isso começam com letra minúscula).

Vantagem: São extremamente rápidos e gastam pouquíssima memória.
